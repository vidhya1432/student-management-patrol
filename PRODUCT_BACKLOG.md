# Product Backlog — Student Management Portal

| Priority | User story | Acceptance criteria |
|---|---|---|
| Must | As a visitor, I want a home page so I can learn about the portal. | The page has an introduction and links to the other pages. |
| Must | As a student, I want to register so I can submit my details. | The form includes name, email, and course fields. |
| Must | As a visitor, I want to view courses. | The page lists available courses and descriptions. |
| Should | As a visitor, I want to learn about the portal. | The page explains the portal’s purpose. |
| Should | As a visitor, I want to contact the institution. | The page shows contact details and a message form. |
